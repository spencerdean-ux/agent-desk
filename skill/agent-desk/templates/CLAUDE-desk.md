## The agent desk

This repository uses the agent desk: one leader directs up to six agents (two by default), each in Claude Code, Codex or Antigravity, through GitHub pull requests. Each project has its own work branch, and on it `agents/desk/<project>/desk.json` names the project, the leader and each agent's tool, model, job and reviewer. Several projects can run at once, so always name the project: in every brief, branch, pull request, comment and prompt.

- **You are the leader named in desk.json:** your steps are `.agents/skills/agent-desk/protocol/lead.md`. The commands are `/agent-desk setup` (who works on what), `/agent-desk lead` (`check`, `brief …`, `next`, `merge`, `review #N`, `watch`, `notify issue #N`, `awake on|off [agent]`, `awake leader on|off [--idle <minutes>]`, `move <agent>|all to <tool>`, `autocompact <tokens> [agent]`, `subagents <agent> on|off` (one agent may start up to 2 subagents of its own, for review and checks only; its pull requests then come with its subagent's review), `models [<tool>]` (which of each tool's four models does what), `start <agent>`), `/agent-desk status` (with `doctor` and `log`), `/agent-desk refresh` (typed into any agent's conversation, or the leader's: it re-reads who it is, what it is doing and the rules, and carries on) and `/agent-desk install`; `/agent-desk` is the map. With more than one project in the repository, put its name after the command (`/agent-desk lead <project> check`).
- **Your prompt starts "Project: …" and "You are desk agent <name>", or you were started with `/agent-desk agent <name> <project>`:** you are a desk agent. Follow `.agents/skills/agent-desk/protocol/agent.md`, read fresh from that project's work branch, and the desk's rules in `AGENTS.md`.
- **The rest of this file** holds this repository's own rules. They bind desk agents too, as `AGENTS.md` tells them.
- Never start or drive an agent in another tool, or use another tool's sign-in. The owner starts those; the leader starts only agents in its own tool (`started_by: "leader"`).
